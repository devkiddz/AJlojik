# Test Checklist

## Store product rails

- [ ] Mobile shows two complete product cards and part of the next.
- [ ] Tablet cards are visibly one size step smaller.
- [ ] Desktop cards fill their rail item without empty right-side space.
- [ ] The first and last cards retain clean edge spacing.
- [ ] Rail arrows move by exactly one card.
- [ ] Product names, prices, variants, and cart controls remain readable.

## Customer dashboard

- [ ] Dashboard outer gutters are consistent on mobile, tablet, and desktop.
- [ ] Journey cards no longer feel oversized.
- [ ] Journey card rows remain readable without vertical clipping.
- [ ] Suggested Products and Picked for You display denser previews.
- [ ] Rail arrows and mobile dots remain accurate.
- [ ] Very wide screens show four journey cards when space permits.

## Feed

- [ ] Feed modules no longer have unusually large desktop gaps.
- [ ] Collections, promotions, Shopping Lists, and Reels remain visually separated.
- [ ] No horizontal page overflow is introduced.

## Discovery Hub

- [ ] Hub header is more compact.
- [ ] Group tabs remain scrollable.
- [ ] Active group switching remains perfect.
- [ ] Hub content retains safe bottom spacing.
- [ ] Search and Hub product handoff still work.

## Regression

- [ ] Search System unchanged.
- [ ] Shopping Lists unchanged.
- [ ] Experience History unchanged.
- [ ] Product previews still open.
- [ ] Add-to-cart controls still work.
