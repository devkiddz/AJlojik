# AJ Logik — MS11.09.4 Production Closure

This final drop closes the Live Support implementation without changing the
customer or agent interaction model that passed MS11.09.2 and MS11.09.3.

## Added

- Seven-day retention for transient Support live events.
- Cleanup of presence records that expired more than 24 hours ago.
- Automatic cleanup scheduling from the canonical live-event publisher.
- Permission-protected Admin diagnostics endpoint:
  - `GET /api/admin/support/live/health`
  - `POST /api/admin/support/live/health` with `{ "action": "prune" }`
- Deterministic source-contract verification:
  - `npm run verify:support-live`

## Two-browser production test

Open the same Support Case in separate authenticated browser contexts:

```text
Customer: /support/[caseId]
Admin:    /admin/support/[caseId]
```

Validate:

1. Both indicators become Live.
2. Each side sees the other become online.
3. Typing appears remotely and clears automatically.
4. Messages arrive without manual refresh.
5. Incoming messages are marked read while the case is open.
6. The actively viewing recipient does not receive a duplicate notification.
7. Closing one tab changes remote presence within approximately 30 seconds.
8. Disconnecting and reconnecting the network restores the stream.
9. Messages sent after reconnection remain persisted after refresh.
10. The Admin health endpoint returns runtime diagnostics.
