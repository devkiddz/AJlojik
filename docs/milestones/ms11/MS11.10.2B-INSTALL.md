# AJ Logik — MS11.10.2B Quick Support Unread Badge & Minimized State

## Included

- Numeric unread badge on the global Support launcher.
- `99+` cap for large unread totals.
- Latest agent-reply preview while the panel is minimized.
- Passive Support SSE stream for immediate attention updates.
- The passive stream does not touch customer presence and does not falsely show
  a minimized customer as online.
- Workspace-scoped `open` or `minimized` panel persistence.
- Open Support panel restoration after refresh and customer navigation.
- Automatic minimization when the panel is closed.
- Automatic panel closure when entering `/support`, `/admin`, `/vendor`, auth,
  offline or delivery-access operational routes.
- Existing Quick Chat mark-read behavior clears the badge when opened.

## Install

Extract the ZIP into the AJ Logik project root, then run:

```powershell
node .\apply.ms11.10.2b-quick-support-unread-minimized-state.mjs
Remove-Item .\apply.ms11.10.2b-quick-support-unread-minimized-state.mjs

npm run verify:support-quick-unread
npm run verify:support-quick-continuity
npm run verify:support-quick-chat
npm run verify:support-live
npm run typecheck
npm run lint
npm run build
```

No migration, schema change or dependency installation is required.

## Two-browser test

1. Customer opens a Quick Support Case, then closes the panel.
2. Agent replies from `/admin/support/[caseId]`.
3. Without refreshing the customer page, confirm:
   - the Support badge increases;
   - a compact **New Support reply** preview appears;
   - the customer is not falsely shown online just because the panel is closed.
4. Open the panel and confirm the badge clears.
5. Leave the panel open, refresh, and confirm the active case reopens.
6. Close the panel, refresh, and confirm it remains minimized.
7. Switch workspace and confirm the stored state and unread count follow only
   the selected workspace.
8. Open the full `/support/[caseId]` route and confirm the compact panel closes.
