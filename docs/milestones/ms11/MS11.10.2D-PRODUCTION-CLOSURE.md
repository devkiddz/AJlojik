## Install

Extract the ZIP into the AJ Logik project root, then run:

```powershell
node .\apply.ms11.10.2d-mobile-reliability-production-closure.mjs
Remove-Item .\apply.ms11.10.2d-mobile-reliability-production-closure.mjs

npm run verify:support-quick-production
npm run verify:support-quick-history
npm run verify:support-quick-unread
npm run verify:support-quick-continuity
npm run verify:support-quick-chat
npm run verify:support-live
npm run typecheck
npm run lint
npm run build
```

No migration, Prisma schema change or dependency installation is required.

## Required closure test

### Mobile viewport

1. Open Quick Support on a phone or narrow browser.
2. Focus the message composer.
3. Confirm the composer remains visible above the keyboard.
4. Scroll the transcript and confirm the page behind the panel does not move.
5. Rotate the device and confirm the panel recalculates without clipping.

### Network recovery

1. Open an active case.
2. Disable the network.
3. Confirm the Offline banner appears and sending is disabled while the draft remains.
4. Restore the network.
5. Confirm reconnecting returns to Live, or press Retry.
6. Confirm no transcript messages are duplicated after recovery.

### Switching and duplicate protection

1. Rapidly switch between two cases several times.
2. Confirm the final selected case remains visible and no older response replaces it.
3. Double-click Send or press Enter and click Send almost simultaneously.
4. Confirm only one customer message is created.
5. Send, then immediately switch cases; confirm the message remains attached to the original case.

### Two-browser live test

1. Keep Customer Quick Support open in one browser.
2. Keep the matching Admin Support Case open in another.
3. Exchange messages in both directions.
4. Confirm live delivery, presence, typing, unread clearing and minimized attention.
5. Close the customer panel and reply from Admin to two recent cases.
6. Confirm the launcher summary refreshes without falsely marking the customer online.
