# AJ Logik — MS11.09.2 Live Customer and Agent Workspaces

This drop subscribes the existing customer and Admin Support Case screens to
the persistent SSE transport from MS11.09.1.

## Included

- Shared `useSupportLiveCase` EventSource client.
- Live / Connecting / Reconnecting / Offline status indicator.
- Customer workspace automatic authoritative reload.
- Agent workspace automatic authoritative reload.
- Incoming customer messages are marked read while that case screen is open.
- Transcript automatically follows newly received messages.
- Existing GET, PATCH, permissions and persisted message services remain
  unchanged.
- Browser EventSource reconnects with the SSE event cursor.

## Not included yet

- Typing indicators.
- Agent availability and presence.
- Cross-case live queue counters.
- Active-conversation notification suppression.

Those belong to MS11.09.3.

## Prerequisite

MS11.09.1 must already be installed because this drop requires:

- `features/support/supportLiveTypes.ts`
- customer live SSE route
- Admin live SSE route

## Install

```powershell
node .\apply.ms11.09.2-live-support-workspaces.mjs
Remove-Item .\apply.ms11.09.2-live-support-workspaces.mjs

npm run typecheck
npm run lint
npm run build
```

No migration or dependency installation is required.

Do not stage or commit until both MS11.09.1 and MS11.09.2 validate together.
