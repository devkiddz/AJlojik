# AJ Logik — MS11.10.1 Quick Customer Chat & Admin Attention

## Included

- Global customer **Support** launcher.
- Compact Support panel through the RCENTZ Global Overlay authority.
- Silent Support Case creation from the customer’s first message.
- Reuse of the customer’s newest active Support Case.
- Live SSE messages, presence and typing inside the compact panel.
- Full-case continuation through `/support/[caseId]`.
- Fifth Admin attention card: **Open support**.
- Immediate deduplicated Admin todo for every new Support Case.
- Todo completion when a case is assigned or leaves `NEW`.
- Admin todo reconciliation for missed or stale Support cases.

## Install

Extract this ZIP into the AJ Logik project root, then run:

```powershell
node .\apply.ms11.10.1-quick-customer-chat-admin-attention.mjs
Remove-Item .\apply.ms11.10.1-quick-customer-chat-admin-attention.mjs

npm run verify:support-quick-chat
npm run verify:support-live
npm run typecheck
npm run lint
npm run build
```

No Prisma migration, schema update, or dependency installation is required.

## Expected verifier

## Test

1. Sign in as a customer and open `/store`.
2. Tap **Support**.
3. Send a first message.
4. Confirm the panel becomes a live case conversation.
5. Open Admin `/admin` in another browser profile.
6. Confirm **Open support** increased and a Support todo appears.
7. Open the todo and assign the case.
8. Confirm the todo completes and live messaging continues.
