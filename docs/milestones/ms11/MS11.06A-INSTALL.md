# AJ Logik — MS11.06A Schema and Permission Repair

This repairs the partial MS11.06 state where the operation files and migration
exist, but `prisma/schema.prisma` and Admin permissions were not updated.

## Install

Extract this ZIP into the AJ Logik project root:

```powershell
node .\apply.ms11.06a-schema-permission-repair.mjs
Remove-Item .\apply.ms11.06a-schema-permission-repair.mjs

npx prisma format
npx prisma validate
npx prisma generate
npx prisma migrate status

npm run typecheck
npm run lint
npm run build
```

`prisma migrate deploy` does not need to reapply anything when migration
`20260802103000_add_support_commerce_actions` is already recorded. Running it
again is safe, but optional.

## Expected result

- Prisma reports 29 migrations and database schema up to date.
- Generated Prisma Client exports `SupportCommerceActionType`.
- Typecheck has no MS11.06 errors.
- The build contains:
  - `/api/admin/support/cases/[caseId]/operations`

Do not proceed to MS11.07 until this repair is green.
