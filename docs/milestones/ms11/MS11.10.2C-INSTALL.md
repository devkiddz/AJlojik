# AJ Logik — MS11.10.2C Quick Support Multi-Case Continuity

## Included

- Canonical recent Support Case collection in the Quick Support summary.
- Active and resolved/history classification.
- Latest-message preview on each recent case.
- Workspace-scoped selected-case memory.
- Compact case switcher inside Quick Chat.
- Direct restoration of the customer's last selected case.
- Direct switching between active, resolved and closed cases.
- Per-case unread badges inside the switcher.
- **Start another conversation** without closing, replacing or mutating the
  existing Support Case.
- Full Support history access remains available through `/support`.
- Recent payload is bounded to 20 cases while totals still describe the full
  customer case collection returned by the resolver.

## Install

Extract the ZIP into the AJ Logik project root, then run:

```powershell
node .\apply.ms11.10.2c-quick-support-multi-case-history.mjs
Remove-Item .\apply.ms11.10.2c-quick-support-multi-case-history.mjs

npm run verify:support-quick-history
npm run verify:support-quick-unread
npm run verify:support-quick-continuity
npm run verify:support-quick-chat
npm run verify:support-live
npm run typecheck
npm run lint
npm run build
```

No migration, schema change or dependency installation is required.

## Test

1. Open Quick Support with an existing active case.
2. Expand **Support conversations** and confirm the active case appears.
3. Click **+** and send a new first message.
4. Confirm a separate Support Case is created and the original remains intact.
5. Switch between both active cases from the compact panel.
6. Resolve or close one case from Admin.
7. Confirm it moves to **Resolution history** and remains directly readable.
8. Refresh with a non-default case selected and confirm that same case restores.
9. Switch workspace and confirm selected-case memory does not leak.
10. Open **Full Support history** and confirm `/support` remains the complete
    dedicated customer workspace.
