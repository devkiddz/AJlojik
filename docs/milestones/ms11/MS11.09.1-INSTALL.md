# AJ Logik — MS11.09.1 Live Transport Foundation

## Architecture

This drop adds a database-backed Server-Sent Events transport around the
existing Support Case and Communication Conversation persistence.

The database remains the source of truth. The stream carries invalidation
events, and later client workspaces will reload authoritative case data when
events arrive.

This avoids an in-memory event bus that would fail across multiple production
server instances.

## Included

- Persistent `SupportLiveEvent` event log.
- Customer-authorized Support SSE endpoint.
- Admin-authorized Support SSE endpoint.
- Cursor recovery through `Last-Event-ID` or `?after=`.
- Automatic heartbeat and reconnect boundary.
- Events for messages, assignments, status changes, notes, escalations and
  resolutions.
- Soft event publication: a transport-event failure never blocks a persisted
  Support operation.

## Not included yet

Customer and Agent workspaces do not subscribe to the stream in this drop.
Typing, presence and active-conversation notification suppression belong to
the next sequences.

## Install

Extract into the AJ Logik project root:

```powershell
node .\apply.ms11.09.1-live-transport-foundation.mjs
Remove-Item .\apply.ms11.09.1-live-transport-foundation.mjs

npx prisma format
npx prisma validate
npx prisma generate
npx prisma migrate status
npx prisma migrate deploy

npm run typecheck
npm run lint
npm run build
```

## Expected

- Prisma reports 31 migrations.
- No pending migration after deploy.
- Routes include:
  - `/api/support/cases/[caseId]/live`
  - `/api/admin/support/cases/[caseId]/live`
- Typecheck and build complete successfully.

Do not stage or commit until the validation output has been reviewed.
