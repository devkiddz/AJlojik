# AJ Logik — MS11.09.3 Presence, Typing and Reliability

## Included

- Customer and Support-agent online presence.
- Typing indicators with automatic four-second expiry.
- Ten-second presence heartbeat with a thirty-second stale cutoff.
- Five-second SSE presence snapshots.
- Best-effort leave handling when the tab closes.
- Automatic agent read-state updates while the case is open.
- Current-conversation unread synchronization.
- Notification suppression for a recipient actively viewing the Support Case.
- Offline and reconnect behavior continues to preserve saved messages.

## Reliability model

Presence is stored in PostgreSQL rather than process memory. A crashed tab,
lost network connection or server restart cannot leave someone permanently
online because every record expires unless its heartbeat is renewed.

Typing state is also time-bound, preventing stuck typing indicators.

## Prerequisites

MS11.09.1 and MS11.09.2 must already be installed.

## Install

```powershell
node .\apply.ms11.09.3-presence-typing-reliability.mjs
Remove-Item .\apply.ms11.09.3-presence-typing-reliability.mjs

npx prisma format
npx prisma validate
npx prisma generate
npx prisma migrate status
npx prisma migrate deploy

npm run typecheck
npm run lint
npm run build
```

## Expected

- Prisma reports 32 migrations.
- No pending migration after deployment.
- Customer and Admin case pages show remote online state.
- Typing appears across the two screens without refreshing.
- Messages still persist when the live connection is interrupted.
- An actively viewing recipient does not receive a duplicate Support
  notification for that open conversation.

Do not stage or commit until validation and two-browser testing are complete.
