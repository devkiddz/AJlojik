# AJ Logik — MS11.10.2A Quick Support Summary & Unread Continuity

## Included

- Canonical server-side active Support Case resolver.
- Workspace-scoped Quick Support summary endpoint.
- Total customer Support unread count.
- Latest agent-reply preview metadata.
- Active/open/total Support Case counts.
- Workspace-safe client summary hook.
- Summary refresh on focus, invalidation and a 20-second continuity interval.
- Quick Support launcher changes to **Continue Support** when an active case exists.
- Quick Chat restoration now uses the canonical summary rather than downloading and guessing from the full case list.
- Summary invalidation after reads and sends.

This phase establishes the authoritative continuity layer. The visible unread
badge and minimized-state behavior follow in MS11.10.2B.

## Install

Extract the ZIP into the AJ Logik project root, then run:

```powershell
node .\apply.ms11.10.2a-quick-support-summary-unread-continuity.mjs
Remove-Item .\apply.ms11.10.2a-quick-support-summary-unread-continuity.mjs

npm run verify:support-quick-continuity
npm run verify:support-quick-chat
npm run verify:support-live
npm run typecheck
npm run lint
npm run build
```

No migration, schema change or dependency installation is required.

## Expected continuity verifier

```text
AJ Logik Quick Support continuity contract is complete.

```

## Test

1. Sign in as a customer with no active Support Case: launcher reads **Support**.
2. Start a Quick Chat.
3. Close the panel: launcher reads **Continue Support**.
4. Refresh or navigate: the same active case is restored.
5. Switch workspaces: Support continuity resets to the selected workspace.
6. Open `/api/support/quick-chat/summary` while authenticated and confirm the
   JSON contains `unreadCount`, `activeCase`, and `latestAgentReply`.
