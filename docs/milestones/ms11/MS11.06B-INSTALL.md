# AJ Logik — MS11.06B Schema and Permission Repair

This replaces MS11.06A, whose installer stopped before modifying the project
because `String.prototype.matchAll` was called with non-global regular
expressions.

## Install

Extract this ZIP into the AJ Logik project root and run:

```powershell
node .\apply.ms11.06b-schema-permission-repair.mjs
Remove-Item .\apply.ms11.06b-schema-permission-repair.mjs

npx prisma format
npx prisma validate
npx prisma generate
npx prisma migrate status

npm run typecheck
npm run lint
npm run build
```

Do not run the original MS11.06 or MS11.06A installer again.

## Expected result

- Prisma reports 29 migrations and the database is up to date.
- Prisma Client exports `SupportCommerceActionType`.
- Typecheck completes without the previous 28 MS11.06 errors.
- The build includes `/api/admin/support/cases/[caseId]/operations`.

Do not rerun MS11.07 until this repair is green.
