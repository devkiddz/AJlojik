# RCENTZ Intelligence Decisions

## D-001 — Resolution-first architecture

The durable domain object is a Resolution. Messages remain supporting history.

## D-002 — Adapter-based context

Identity, experience, commerce, behaviour, and operations are collected independently through context adapters.

## D-003 — Planning is provider-neutral

The deterministic planner establishes stable behaviour. External AI providers may later improve interpretation and ranking behind the same contracts.

## D-004 — No direct provider mutations

Intelligence providers cannot write directly through Prisma. All changes must pass through the governed Action Registry.

## D-005 — Existing Assistant remains operational

Migration happens underneath the current Customer, Admin, and Vendor Assistant surfaces until the Resolution Workspace replaces them safely.
