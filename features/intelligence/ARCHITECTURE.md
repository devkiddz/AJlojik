# RCENTZ Intelligence Architecture

RCENTZ Intelligence is a Resolution system, not a chatbot.

```text
Goal
→ Context
→ Plan
→ Evidence
→ Prepared actions
→ Approval
→ Execution
→ Verified outcome
```

## Permanent boundaries

- Providers may propose; RCENTZ validates and authorizes.
- The planning layer does not receive direct Prisma authority.
- All mutations pass through typed application services.
- Customer, Admin, and Vendor context remains workspace-scoped.
- Vendor changes remain vendor-scoped and approval-aware.
- Conversation is an input channel; Resolution is the durable product.
